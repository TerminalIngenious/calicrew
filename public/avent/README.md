# Les photos de l'event de décembre

Un fichier par carte, nommé d'après son `slug` dans `src/lib/avent.ts` :

    public/avent/eva-elfie.webp
    public/avent/bunny-blue.webp
    …

Format attendu : **WebP**, portrait, au moins 800 × 1070 px. Le cadrage est
fait par la carte (`object-fit: cover`, ancré en haut), donc un portrait
centré sur le visage marche sans retouche.

Tant qu'un fichier manque, la carte affiche les initiales sur un fond givré.
Rien ne casse, et la carte reste montrable.
